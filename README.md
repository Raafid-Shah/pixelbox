# PIXELBOX v3 · The Late Byte Edition
Vertical slice of the plan: engine core, bitmap text, UI panels, WebGL2 CRT shader (2D fallback), Broadcast Wood body,

Drop `PressStart2P.woff2` (+ OFL licence) into `public/fonts/`; text falls back to monospace until then.
